# Buddies

Study-buddy profiles live here, one file each: `<name>.profile.md`.

## Getting one

Your buddy runs `/nihongo-buddy export` in their own clone, which writes `me/profile.share.md`. They send you that file — Slack, email, gist, whatever. You drop it anywhere and run:

```
/nihongo-buddy add <name>
```

It normalises the file into this directory and tells you where your levels overlap.

Then, any time you want to practise together:

```
/nihongo-buddy plan <name>
```

That writes a plan to `shared/<name>/` designed to be run by the two of you with nothing else — full scripts, inline vocabulary, split information-gap sheets, and an answer key so you can settle disagreements without a fluent speaker.

## What's in a profile

Level, goal, grammar covered, vocabulary themes, weak points, assets. **Not** the journal — nobody's raw attempts get shared, in either direction.

## Different levels are fine

You don't need a buddy at your exact level. Where you differ, the plan assigns roles: the stronger partner asks and teaches, the other responds. Responding is easier than initiating, and teaching is how the stronger one consolidates. Both sides get something.

What *doesn't* work is building activities from everything either of you knows. A single pattern one person hasn't met stops a beginner conversation dead — so plans are built strictly from the overlap. Expect that overlap to look small at first.
